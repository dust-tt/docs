---
title: "EU-hosted models"
description: "Limit an EU workspace to models that Dust hosts in the European Union."
---

Workspaces in Dust's EU region (`https://eu.dust.tt`) can limit their agents to models hosted in the European Union, for example to meet data residency requirements.

## Availability

The **EU-hosted models only** setting is available to workspaces that:

- run in the EU region (`https://eu.dust.tt`), and
- are on a credit-based plan that uses Dust's model hosting, not your own model provider keys (BYOK).

## Turn on EU-hosted models only

1. Make sure every active agent uses an EU-hosted model or an auto model (**Basic**, **Standard**, or **Premium**). If any active agent uses a model that isn't EU-hosted, Dust doesn't turn on the setting and shows "Some active agents may not be eligible for regional models."
2. Go to **Admin** > **Models**.
3. Turn on **EU-hosted models only**.

## What changes

- The model picker and the Agent Builder only offer EU-hosted models.
- Auto models (**Basic**, **Standard**, and **Premium**) only use EU-hosted models.

## Check whether a model is EU-hosted

In workspaces where the setting is available, the model picker shows the EU flag next to each EU-hosted model. The flag is the most up-to-date reference, since Dust adds and retires models regularly.
