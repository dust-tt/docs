title: "What settings / model should I use?"
---


- **Instructions**: write clear, detailed prompts for the agent. Check [Prompting 101: How to Talk to Your Agents](/docs/user-documentation/agents/llm-best-practices/how-to-write-effective-instructions) for more advice.
- **Advanced** > **Model selection**: choose the model the agent runs on, and its reasoning effort.

## Which model should I choose?

Start with an auto model and let Dust route each request to the right model. See [Auto models and the model picker](/docs/user-documentation/agents/model-selection) for the full detail.

| Choice | Use it for |
| --- | --- |
| **Standard** | The right default for almost every agent: drafting, summarizing, answering questions over your knowledge. |
| **Fast** | High-volume, mechanical work: classification, tagging, formatting, routing, extraction, first-pass triage. |
| **Complex** | Hard reasoning, long analysis, code, high-stakes synthesis. |
| A specific model | When you need a guarantee that the agent always runs on one exact model, for example to reproduce a known output. |

Auto models also protect you from provider outages and mean you do not have to migrate agents every time a new frontier model ships.

## What reasoning effort should I set?

Reasoning effort only applies when you pick a specific model. Only the levels that model supports are selectable.

- **Light**: light reasoning effort, faster responses.
- **Medium**: medium reasoning effort, balancing speed and quality.
- **High**: high reasoning effort, longer wait times but higher quality.

Higher effort costs more and can move a model into a higher [model access tier](/docs/user-documentation/admins/usage-seats-and-credits/model-access-tiers).

## Can I change the model without editing the agent?

Yes. Use the model picker in the conversation input bar. It applies to your next message in that conversation only and leaves the agent untouched.
