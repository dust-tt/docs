## What if an AI model provider is having an outage?

A provider outage can affect one model while others remain available in Dust. If you use **Basic**, **Standard**, or **Premium**, no action is required: Dust skips degraded models for new messages. The model picker shows when your auto model uses a temporary replacement.

If you selected a specific model, Dust warns you but does not switch it automatically. You can choose an auto model or another available model. For failed messages and retry precautions, see [Provider outages and automatic fallback](/docs/user-documentation/agents/model-selection#provider-outages-and-automatic-fallback).
