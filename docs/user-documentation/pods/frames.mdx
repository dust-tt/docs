---
title: "Frames"
description: "Pin a live Frame as a Pod banner to show the Pod's status at a glance, and keep it up to date with agents."
---

A Frame is an interactive page an agent builds, like a dashboard, a chart, or a status board. In a Pod, you can pin a Frame as a banner at the top of the Pod, so everyone sees the same live view when they open it. Because the Frame reads the Pod's files, it updates when those files change.

## Pin a Frame as the Pod banner

<Steps>
  <Step title="Create the Frame">
    In a Pod conversation, ask an agent to build the Frame, for example _"Create a Frame showing the status of our open tasks, and keep it compact so it fits as a Pod banner."_
  </Step>
  <Step title="Pin it">
    In the **Files** tab, open the Frame's `...` menu and click **Pin as Pod banner**. You can also click **Pin as Pod banner** from the Frame preview, or ask the agent to pin it.
  </Step>
</Steps>

Only one Frame can be pinned at a time. Pinning a new one replaces the current banner.

## Use the banner

The banner is 280 pixels tall and shows at the top of the Pod. Hover over it to see its controls:

- **Open in full screen**: open the Frame in full size.
- **Hide**: collapse the banner for you. Click **Show** to bring it back.
- **Unpin**: remove the banner for everyone. The Frame stays in the Pod's files.

You can also unpin it from the **Files** tab with **Unpin from banner**.

## Keep the banner up to date

A Frame shows the data it reads. To keep the banner current, keep the files behind it up to date:

- Ask an agent to update the file whenever something changes, for example at the end of each task.
- Ask an agent to use [wake-ups](/docs/user-documentation/agents/tools/wake-ups) to refresh the file on a schedule, like every Monday morning.

## Banner tips

- Design for 280 pixels: show a few key numbers or a short status, not a full report.
- Make sure the Frame works on smaller screens, so it doesn't get cut off.
- Put the details in a separate Frame or file, and link to it from the banner if needed.
