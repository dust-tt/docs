---
title: "Tasks"
description: "Create, assign, and track work in a Pod, start an agent on a task, and keep tasks in sync with tools like Jira, Asana, or Linear."
---

The **Tasks** tab lists the work to do in a Pod. Members and agents can create tasks, assign them, start an agent on them, and mark them done. When an agent starts a task, it gets its own conversation, so you can follow the work and step in at any time.

## Create a task

<Steps>
  <Step title="Open the Tasks tab">
    Open the Pod and click **Tasks**.
  </Step>
  <Step title="Write the task">
    Click **Add a task...** and describe the work. Write it as a clear, self-contained instruction: an agent reads it as its brief when it starts.
  </Step>
  <Step title="Assign it">
    New tasks are assigned to you. To change that, click the assignee button next to the field and pick another member, or **No assignee** if the Pod has more than one member. Then press **Enter** or click **Add**.
  </Step>
</Steps>

Agents can create tasks too, for example after reading a conversation or processing a request. Tasks are grouped by assignee, and unassigned tasks have their own section.

When a new Pod has no conversations yet, an editor can click **Let's go** in the **Conversations** tab to add a few starter tasks. They show in a **Suggestions** card: click **Accept** on the ones to keep, or use **Accept all** or **Dismiss all**.

## Start an agent on a task

<Steps>
  <Step title="Open the start menu">
    Hover over the task and click the play button (**Start working on task**).
  </Step>
  <Step title="Pick the agent">
    Choose the agent and, if needed, add a custom message with extra instructions.
  </Step>
  <Step title="Start">
    Click **Start working**. Use the arrow next to it to choose whether to **Redirect to conversation** or **Stay on tasks**. Dust creates a conversation linked to the task and marks the task as in progress.
  </Step>
</Steps>

To follow the work, click the chat icon on the task (**Open task conversation**), or find the conversation in the **Conversations** tab.

Agents can also start work on a task themselves, without anyone clicking.

## Task states

A task is to do until someone starts it, in progress while an agent works on it in a linked conversation, and done once it's checked.

To mark a task done, click its checkbox. An agent can also mark its own task done at the end of its conversation and explain what it did. Done tasks leave the **Open** list: to see them, pick a period in the status menu (see below), and uncheck a task to reopen it.

## Edit, reassign, or delete a task

- **Edit**: click the task text, change it, and press **Enter**.
- **Reassign**: open the `...` menu on the task, click **Reassign**, and pick another member or **No assignee**.
- **Delete**: open the `...` menu on the task and click **Delete task**.

To find a task, use the filters above the list:

- Switch between **Everyone** and **Mine**.
- Pick a status: **Open** (default), **Done today**, **Done in the last 7 days**, or **Done in the last 30 days**.
- Type in **Filter tasks...** to search by task text, assignee, or source.

## Sync tasks with Jira, Asana, or Linear

Any agent can read and write Pod tasks. To sync them with another tool, use an agent that also has that tool, like [Jira](/docs/user-documentation/agents/tools/jira), [Asana](/docs/user-documentation/agents/tools/asana), or Linear.

- **One-time import**: in a Pod conversation, ask the agent something like _"Read all open Jira tickets assigned to this team and create a matching task in this Pod for each one."_
- **Ongoing sync**: ask the agent to use [wake-ups](/docs/user-documentation/agents/tools/wake-ups) to run the sync on a schedule, for example _"Every weekday morning, create a task in this Pod for each new open Jira ticket in project XYZ, and close the Jira ticket of each task marked done here."_

<Warning>
  A two-way sync can loop if the instructions aren't clear. Say which tool is the source of truth for each kind of change, or sync in one direction per run.
</Warning>
