---
title: "Content and editorial production"
description: "Run a content campaign from brief to publication in one Pod, with agents drafting each piece and tracking reviews."
---

Marketing and communications teams can run a campaign or a content sprint in one Pod. The brief, brand guidelines, drafts, and feedback stay together, and agents write first drafts so the team can focus on review and polish.

## Set up the Pod

| Setting | Recommendation |
| --- | --- |
| Name | One Pod per campaign or sprint, like "Series B launch content". |
| Access | **Restricted**. |
| Members | The writers, designers, and campaign lead. |
| Files | The campaign brief and brand guidelines. Link past content from Company Data for reference. |
| Instructions for agents | The campaign goal, target audience, key messages, and tone of voice. See [Give agents instructions for the Pod](/docs/user-documentation/pods/files#give-agents-instructions-for-the-pod). |

## Start simple

Create a task for each deliverable, like a blog post, social posts, an email, or a press release. Click the play button (**Start working on task**) to hand it to an agent: it drafts the piece from the brief and the brand guidelines. Review the draft and give feedback in the task's conversation, and the agent revises it.

Drafts, feedback, and decisions stay in the Pod, so the whole team sees where each piece stands.

## Add structure

- Ask an agent to build an editorial calendar from the brief as a Frame, and pin it as the Pod banner. Ask the agent to update it as pieces move forward. See [Frames](/docs/user-documentation/pods/frames).
- Add a review step: in the Pod instructions for agents, ask agents to create a "Review" task assigned to the campaign lead each time they finish a draft.
- Add a weekly [schedule](/docs/user-documentation/agents/triggers/schedules) to an agent and pick the Pod under **Where to create this conversation?**. Each week, the agent posts what's drafted, in review, published, and blocked.

## Go further

- At kickoff, ask an agent to create a task for each deliverable and start an agent on each one, so first drafts are ready on day one.
- Ask agents to check every draft against your style guide and SEO rules before they hand it over for review, for example with a skill that holds those rules.
- After publication, schedule an agent that pulls engagement data from your analytics tools and posts a report in the Pod after 7 and 30 days.

## What you get

Campaigns go from brief to publication faster. Agents handle first drafts and status updates, and the team spends its time on review, polish, and decisions.
