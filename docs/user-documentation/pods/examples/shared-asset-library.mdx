---
title: "Shared asset library"
description: "Keep logos, Frame templates, and brand guidelines in one Open Pod so every agent in the workspace uses the same, up-to-date assets."
---

Design, brand, and platform teams can keep their reusable assets in one Open Pod: logos, Frame templates, brand guidelines, and reference data. Everyone in the workspace can read an Open Pod, so agents can use these assets from any conversation or Pod, and the team that owns them updates them in a single place.

## Set up the Pod

| Setting | Recommendation |
| --- | --- |
| Name | A clear name, like "Brand assets" or "Shared templates". |
| Access | **Open**, so everyone in the workspace can read the files. |
| Members | The design or platform team members who own the assets. |
| Files | One folder per type of asset. See below. |
| Instructions for agents | What each folder contains and which files are the reference versions. See [Give agents instructions for the Pod](/docs/user-documentation/pods/files#give-agents-instructions-for-the-pod). |

Organize the **Files** tab with folders, for example:

- `images/`: logos, illustrations, and product screenshots.
- `frames/`: reference Frames for reports, dashboards, and slides.
- `brand/`: color palettes, typography, and brand guidelines.
- `data/`: shared reference tables, like lookup CSV files.

<Note>
  People who join an Open Pod become members, and members can add, change, and delete files. To keep the library under the team's control, let others read it without joining.
</Note>

## Start simple

Upload the assets once. Anyone can open the Pod, browse the **Files** tab, and download what they need. To use an asset, point an agent to it by name, for example: _"Use the logo from the Brand assets Pod."_

Editors can add the most used files, like the brand guidelines, as Pod tabs so they're one click away. See [Show files as Pod tabs](/docs/user-documentation/pods/files#show-files-as-pod-tabs).

## Build from templates

From any conversation or Pod, ask an agent to start from a reference Frame: _"Use the quarterly report Frame from the Brand assets Pod as the base for this review."_ The agent copies the template, adapts it, and saves the result where you're working. The original stays untouched. When the team updates a template, the next agent runs use the new version.

## Go further

- In the instructions of agents that create reports, slides, or other visual content, tell them to check the Brand assets Pod for templates before they start.
- Keep a changelog document in the Pod, and ask agents to add an entry each time a template changes, so people know what's new.

## What you get

Agents produce on-brand content without extra instructions, and the team maintains one source of truth instead of copies scattered across conversations and Pods.
