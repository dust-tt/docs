---
title: "Admin controls"
description: "Choose whether members can create open Pods and upload files to Pods, and access a Pod as an admin when you need to."
---

Workspace admins can set two policies for every Pod in the workspace: whether members can create open Pods, and whether people can add files to Pods by hand. Admins can also open any Pod, even a restricted one, when they need to step in.

## Set Pod policies

Go to **Admin** > **Governance** and open the **Pods, Frames & Files** tab. In the **Pods** section:

| Setting | Options |
| --- | --- |
| **Restricted and open Pods** | **Restricted and open Pods** (default): members can create both kinds. **Restricted Pods only**: members can only create restricted Pods. |
| **Pod files** | **Manual updates allowed** (default): members can upload files to Pods. **Manual updates disabled**: only agents can add files, and the **Add** button is hidden in the **Files** tab. |

Turning off manual updates is useful when Pod files should only come from agents and approved sources, for example in regulated teams.

## Access a Pod as an admin

Admins can open a restricted Pod they're not a member of, for example to help a team or check its content.

<Steps>
  <Step title="Find the Pod">
    Open the Pod from a link, or find it in **Browse Pods**.
  </Step>
  <Step title="Confirm access">
    Click **Access as admin** and confirm. You join the Pod as a member.
  </Step>
</Steps>

Every admin access is recorded in the audit logs as `project.admin_access_granted`. See [Audit logs](/docs/user-documentation/admins/audit-logs/audit-logs).
