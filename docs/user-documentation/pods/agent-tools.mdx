---
title: "Agent tools"
description: "See the tools agents use to work in a Pod: search its knowledge, manage files and tasks, update its settings, and pin Frames."
---

Agents working in a Pod get the Pods skill automatically. It gives them tools to search the Pod, manage its files and tasks, and update its settings, so you can ask for these things in plain language in any Pod conversation. You don't need to add anything in the Agent Builder.

## Search and read the Pod

| Tool | What the agent does |
| --- | --- |
| `get_information` | Reads the Pod's description, members, settings, and linked data. |
| `semantic_search` | Searches the Pod's files, linked data, and conversations by meaning. |

## Manage files

| Tool | What the agent does |
| --- | --- |
| `add_file` | Saves a new file to the Pod, like a report or a generated document. |
| `update_file` | Replaces the content of a file. |
| `add_content_node` | Links data from Company Data to the Pod. |
| `remove_content_node` | Removes linked data from the Pod. |

## Manage tasks

| Tool | What the agent does |
| --- | --- |
| `list_tasks` | Lists the Pod's tasks, with their state and assignee. |
| `create_tasks` | Creates up to 30 tasks at once. |
| `update_tasks` | Edits tasks, reassigns them, or marks them done. |
| `start_task_agent` | Starts an agent on a task, in a new conversation linked to it. |

## Update the Pod

| Tool | What the agent does |
| --- | --- |
| `edit_information` | Updates the Pod's description. |
| `set_default_agent` | Sets the agent pre-selected in new Pod conversations. |
| `set_pinned_frame` | Pins or unpins a Frame as the Pod banner. |
| `list_members` | Lists the Pod's members and their roles. |
| `move_conversation` | Moves a conversation into the Pod. |

## Example requests

- _"Summarize this conversation and save it as a file in this Pod."_
- _"Create one task for each action item from today's meeting notes, and assign them to the right people."_
- _"Start @Writer on the blog draft task."_
- _"Pin the status Frame as the Pod banner."_
