---
title: "Dust Support"
description: "Let your agent answer questions about Dust using the Dust documentation, the community Q&A, and the web."
---

Dust Support lets an agent answer questions about Dust itself: how to use a feature, what Dust can and can't do, or why something doesn't work as expected. **@dust** uses it when you ask about Dust, and you can add it to your own agents.

## What your agent can do with Dust Support

| Capability | What it does |
| :--- | :--- |
| Check the docs | Reads the Dust documentation before it answers. |
| Check the community | Looks at questions and answers on the [Dust community page](https://community.dust.tt). |
| Search the web | Searches the web and reads pages when the docs don't cover the question. |
| Help you troubleshoot | Asks questions that help you narrow down what's going on. |

Dust Support only uses public sources. If it can't find an answer, it says so instead of guessing.

## When to use Dust Support

Ask questions like:

- "How do I connect Snowflake?"
- "What's the file size limit for uploads?"
- "Why isn't my agent finding the latest documents from Notion?"

Dust Support can't see your workspace settings, your account, or your billing. For those questions, contact Dust support.

## Add Dust Support to an agent

**@dust** already has Dust Support: ask it a question about Dust, and it turns the skill on.

To add Dust Support to your own agent:

<Steps>
  <Step title="Open your agent in the Agent Builder">
    Create an agent, or open one you can edit.
  </Step>
  <Step title="Add the skill">
    In **Capabilities and knowledge**, click **Add capabilities** and select **Dust Support**.
  </Step>
  <Step title="Save your agent">
    People using the agent can now ask it questions about Dust.
  </Step>
</Steps>

Agents with [Discover Skills](/docs/user-documentation/agents/discover-skills) can also find Dust Support and turn it on when someone asks about Dust. To use it in one conversation without changing an agent, type `/` in the message bar and select **Dust Support**.

## Example instructions

```text
When someone asks how to do something in Dust, use Dust Support, and link to the docs page you used.
```
