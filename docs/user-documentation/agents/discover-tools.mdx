---
title: "Discover Tools"
description: "Let your agent find and turn on tools from your workspace when a task needs them."
---

Discover Tools lets an agent find the tools your workspace has set up and turn one on when a task needs it, like reading a Jira ticket or updating a HubSpot deal. You don't need to add every tool to the agent ahead of time. **@dust** already does this, and you can add it to your own agents.

## What your agent can do with Discover Tools

| Capability | What it does |
| :--- | :--- |
| List available tools | Sees the tools in **Company Data** and in the other Spaces the agent uses, if they can be added during a conversation. |
| Turn on a tool | Turns on the tool it needs, for the current conversation. |
| Use the tool | Calls the tool's actions to read live data or make changes in another app. |

Once the agent turns on a tool, the tool stays on for that agent for the rest of the conversation. To learn which tools can be added during a conversation, see [JIT tools](/docs/user-documentation/agents/tools/jit-tools).

## When to use Discover Tools

Add Discover Tools when your agent:

- Handles requests that could need many different apps, like a general assistant for your team.
- Needs a tool only now and then, and you'd rather not add it ahead of time.

If your agent uses the same tool for every request, add that tool to the agent directly.

## Add Discover Tools to an agent

**@dust** already discovers tools on its own.

To add Discover Tools to your own agent:

<Steps>
  <Step title="Open your agent in the Agent Builder">
    Create an agent, or open one you can edit.
  </Step>
  <Step title="Add the skill">
    In **Capabilities and knowledge**, click **Add capabilities** and select **Discover Tools**.
  </Step>
  <Step title="Save your agent">
    The agent can now turn on tools from your workspace when a task needs them.
  </Step>
</Steps>

## Example instructions

```text
When a request needs data from another app, like a Jira ticket or a HubSpot deal, use Discover Tools to turn on the right tool before you answer.
```

## Limits

- Discover Tools only finds tools that were already added in **Spaces** > **Tools**. It can't connect a new app.
