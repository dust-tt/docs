---
title: "Troubleshooting your agent"
description: "Fix the most common problems with agent answers: wrong sources, made-up facts, and inconsistent formats."
---

Most agent problems come from instructions that leave room for interpretation, or from knowledge that's too broad. Start with the symptom that matches what you see, change one thing at a time, and test the result in the preview of the Agent Builder.

## The agent doesn't find the right source

- **Limit the knowledge.** Give the agent only the sources it needs. For example, a process support agent only needs your process pages, not your whole Notion workspace.
- **Say where to look.** Add hints to the instructions, like "look for documents titled X or that mention Y."
- **Describe each source.** When you add knowledge, describe what the data contains. The agent uses the description to decide when to search it.
- **Organize your documents.** Sometimes the fix is on the data side: group related pages in one folder, or keep a dedicated Slack channel for a topic.

## The agent makes things up

- **Allow it to not know.** Models try to answer even when they don't have the information. Add an instruction like "If you don't find the answer in the documents, say you don't know."
- **Say what to avoid.** For example: "Don't speculate. Only use facts from the documents you found."
- **Ask for steps.** Tell the agent to work step by step, like "First search the documents, then summarize what you found, then answer."
- **Try another model.** For complex tasks, choose a more capable model in the model picker. See [Auto models and the model picker](/docs/user-documentation/agents/model-selection).
- **Start a new conversation.** Very long conversations make it harder for the model to keep track of everything. When answers drift, start fresh.

## The output format isn't consistent

- **Describe the format.** State exactly how you want the answer presented, like "Present the data in a table with columns A, B, and C."
- **Give an example.** Paste an example of the output you expect in the instructions.
- **Use structured output.** If another system reads the answers, set a JSON schema. See [Structured output format](/docs/user-documentation/agents/structured-output-format).

## Get help from Sidekick

In the Agent Builder, [Sidekick](/docs/user-documentation/agents/default-agents/agent-builder-sidekick) can review your instructions, explain why the agent behaves a certain way, and suggest targeted changes. Accept the ones that make sense, then test again in the preview.
