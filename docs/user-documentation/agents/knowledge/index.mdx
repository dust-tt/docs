title: "Knowledge"
description: "Give an agent access to your company data and choose how it reads that data: search, analytics on tables, full documents, or structured extraction."
---

Knowledge lets an agent use your company data when it answers. You pick the data the agent can use, then choose how it reads that data. The data comes from your [data sources](/docs/user-documentation/data-sources/overview): connections, folders, and websites, which admins and builders manage in Spaces.

## Add knowledge to an agent

<Steps>
  <Step title="Open the agent in the Agent Builder">
    In **Capabilities and knowledge**, click **Add knowledge**.
  </Step>
  <Step title="Select data sources">
    In **Select data sources**, pick a Space, then select the connections, folders, websites, or specific pages and channels the agent needs. Click **Next**.
  </Step>
  <Step title="Choose a method">
    Pick how the agent uses the data (see the table below), describe what the data contains, and save the agent.
  </Step>
</Steps>

## Choose a method

| Method | Use it for | What the agent does |
| --- | --- | --- |
| [Content search](/docs/user-documentation/agents/knowledge/search-data-sources) | Most questions about documents, like policies, wikis, tickets, or meeting notes | Searches the data by meaning and answers from the most relevant passages, with links to the sources. |
| [Analytics](/docs/user-documentation/agents/knowledge/table-queries) | Numbers and counts from tables, spreadsheets, and databases | Writes a SQL query, runs it on the selected tables, and answers from the results. |
| [Include all data](/docs/user-documentation/agents/knowledge/include-data) | Summaries and reviews that need complete documents, like a weekly digest | Loads whole documents, most recent first, until it reaches the model's limit or your time range. |
| [Advanced processing](/docs/user-documentation/agents/knowledge/extract-data) | Pulling the same fields out of many documents | Reads the documents and extracts the information in a structure you define. |

Start with **Content search** unless the question is about numbers or needs every document. You can add several knowledge configurations to the same agent, for example search on your wiki and analytics on a sales spreadsheet.

<Tip>
  An agent with a small set of relevant sources usually answers better than one with access to everything. If you want an agent to find the right sources on its own, add [Discover Knowledge](/docs/user-documentation/agents/discover-knowledge) instead.
</Tip>
