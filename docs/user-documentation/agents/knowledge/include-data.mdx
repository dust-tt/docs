---
title: "Include data"
description: "Load whole documents into an agent's context, most recent first, for summaries and reviews that need everything rather than the best matches."
---

With **Include all data**, the agent reads whole documents instead of searching for passages. It loads the most recent documents first and keeps going until it reaches the model's limit or the time range you set. Use it when the answer depends on everything in a set of documents, not only the parts that match the question.

## When to use it

Include data works well for recurring summaries and reviews, for example:

- A weekly digest of a Slack channel.
- A summary of last month's meeting notes.
- A review of every support ticket from yesterday.

For questions that only need a few relevant passages, like "What's our parental leave policy?", [search](/docs/user-documentation/agents/knowledge/search-data-sources) is faster and covers more data.

## How much data the agent sees

A model can only read a limited amount of text at once, called its [context window](/docs/user-documentation/agents/llm-best-practices/understanding-llms-context-windows). When the selected data doesn't fit, the agent keeps the most recent documents and tells you the cutoff in the answer details, for example "Only includes documents since" a given date.

To control what the agent reads, set a time range when you configure the knowledge, like the last 7 days. A shorter range keeps the agent focused on recent content and makes answers faster.

## Set up include data

<Steps>
  <Step title="Add knowledge">
    In the Agent Builder, in **Capabilities and knowledge**, click **Add knowledge**.
  </Step>
  <Step title="Select data sources">
    Pick a Space and select the folders, channels, or pages the agent needs. Click **Next**.
  </Step>
  <Step title="Choose Include all data">
    Pick **Include all data**, set a time range if needed, describe what the data contains, and save the agent.
  </Step>
</Steps>

## Limits

- Include data doesn't read tables or spreadsheets. Use [table queries](/docs/user-documentation/agents/knowledge/table-queries) for those.
- On large sources, older documents are left out when the context window is full. Narrow the data or the time range to make sure the agent sees what matters.
