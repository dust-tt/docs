---
title: "Steering: Conversations that keep up with you"
description: "Follow what an agent does in real time, send messages while it works to change its direction, and stop it without losing its progress."
---

You don't need to wait for an agent to finish before you talk to it. While it works, you see each step live, and you can send a new message to add context or change its direction. This is called steering.

## Follow what the agent does

While the agent works, each step appears in the conversation as it happens: its thinking, tool calls, searches, and file operations. Click a step to see its details.

This helps you to:

- **Catch issues early.** If the agent uses the wrong data or misreads your request, you see it right away.
- **Let it run longer.** When you can see the progress, you can let a long task finish instead of stopping it.
- **Improve your agents.** If you build agents, the live steps show where the instructions are unclear or where the agent gets stuck.

## Send a message while the agent works

You can send a message while the agent is still working. You don't need to stop it or start over.

1. Your message shows **Message queued** with a clock icon. Until the agent reads it, you can edit or delete it from the message menu.
2. The agent finishes its current round of actions. For example, if it started three web searches at the same time, it completes all three.
3. The agent reads your message, with the full context of the conversation.
4. The agent continues, adjusted to your message.

You can send several messages while the agent works. The agent reads them all at the same time.

The agent finishes its current round first so that its work stays consistent. If it stopped in the middle of an action, it could lose track of what it already did.

For example:

- **Change a Frame:** while the agent builds a revenue dashboard, you send "make it a bar chart and split out APAC." The agent changes the dashboard without starting over.
- **Narrow research:** while the agent researches competitors, you send "focus on Europe only." It finishes its current searches, then narrows the scope.
- **Add context:** while the agent drafts a reply to a customer, you send "they're on v1 of the API, not v2." The agent adapts the reply.

## One agent at a time

Only one agent can work in a conversation at a time, so that your messages reach the agent that is working. The selected agent shows in the message input, so you can type your message without a mention.

While an agent works, you can't call a different agent. Wait for the current agent to finish, then mention the other agent.

## Stop an agent

To stop the agent, click **Stop** in the message input while it works. When you stop an agent, it keeps what it already did. Only the next steps are canceled, so you don't lose the work in progress.
