title: "Structured output format"
---


## How to configure

1. Open the agent in Agent Builder.
2. In the **Instructions** section, pick a specific model that supports structured output, next to the **JSON response** button.
3. Click **JSON response**.
4. Paste a valid JSON schema, then save.

## Schema format

The schema must follow this structure:

```json JSON format
{
  "type": "json_schema",
  "json_schema": {
    "name": "your_schema_name",
    "strict": true,
    "schema": {
      "type": "object",
      "properties": {
        "property1": { "type": "string" },
        "property2": { "type": "number" }
      },
      "required": ["property1", "property2"],
      "additionalProperties": false
    }
  }
}
```

## Example

A schema to extract city information:

```json structured output format example

{
  "type": "json_schema",
  "json_schema": {
    "name": "city_info",
    "strict": true,
    "schema": {
      "type": "object",
      "properties": {
        "country": { "type": "string" },
        "state": { "type": ["string", "null"] },
        "city": { "type": "string" },
        "zipcode": { "type": "string" }
      },
      "required": ["country", "state", "city", "zipcode"],
      "additionalProperties": false
    }
  }
}
```

## Supported models

Not all models support structured output. The **JSON response** button is only enabled when the agent uses a specific model that supports it.

All specific models currently offered in the model picker support structured output, except:

* Mistral Small
* Mistral Codestral

Auto models (**Basic**, **Standard**, and **Premium**) don't support structured output. Pick a specific model to use it.
