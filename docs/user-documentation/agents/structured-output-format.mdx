---
title: "Structured output format"
description: "Make an agent answer in a fixed JSON format, so other tools and workflows can read its output."
---

Structured output makes an agent answer in a fixed JSON format that you define with a schema. Use it when another system reads the agent's answers, like a Zapier workflow or an API integration, and needs the same fields every time.


## Set up structured output

<Steps>
  <Step title="Open the agent">
    Open the agent in the Agent Builder.
  </Step>
  <Step title="Pick a specific model">
    In the **Instructions** section, use the model picker to choose a specific model that supports structured output. Auto models don't support it.
  </Step>
  <Step title="Add the schema">
    Click **JSON response**, paste a valid JSON schema, then save the agent.
  </Step>
</Steps>

## Schema format

The schema must follow this structure:

```json JSON format
{
  "type": "json_schema",
  "json_schema": {
    "name": "your_schema_name",
    "strict": true,
    "schema": {
      "type": "object",
      "properties": {
        "property1": { "type": "string" },
        "property2": { "type": "number" }
      },
      "required": ["property1", "property2"],
      "additionalProperties": false
    }
  }
}
```

## Example

A schema to extract city information:

```json structured output format example

{
  "type": "json_schema",
  "json_schema": {
    "name": "city_info",
    "strict": true,
    "schema": {
      "type": "object",
      "properties": {
        "country": { "type": "string" },
        "state": { "type": ["string", "null"] },
        "city": { "type": "string" },
        "zipcode": { "type": "string" }
      },
      "required": ["country", "state", "city", "zipcode"],
      "additionalProperties": false
    }
  }
}
```

## Supported models

Not all models support structured output. The **JSON response** button is only enabled when the agent uses a specific model that supports it. Auto models (**Basic**, **Standard**, and **Premium**) don't support structured output, so pick a specific model to use it.
