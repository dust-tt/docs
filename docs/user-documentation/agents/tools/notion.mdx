With the Notion tool, your agents can search your Notion workspace, read pages and databases, and create or update content. Dust connects to Notion's official MCP server, so the tools and their behavior come from Notion.

## What your agent can do in Notion

| Action | What it does | Changes data |
| --- | --- | --- |
| **Search and read** | Search your Notion workspace and connected sources, then read pages, databases, and their content. | No |
| **Query databases** | Query database views and data sources, including meeting notes. | No |
| **Read comments and people** | Read the comments on a page, and find users and teamspaces. | No |
| **Create and update pages** | Create pages, update their content and properties, move them, or duplicate them. | Yes |
| **Create and update databases** | Create databases and views, and change a database's properties. | Yes |
| **Comment** | Add a comment to a page or reply in a discussion. | Yes |

For the full and current list of tools, see [Notion's MCP documentation](https://developers.notion.com/docs/mcp-supported-tools).

## Before you start

- **In Dust:** you need to be an admin to add Notion.
- **In Notion:** agents can only reach the pages and databases that the connected Notion account can access.

## Connect Notion (admins)

<Steps>
  <Step title="Add the tool">
    Go to **Spaces** > **Tools**, click **Add tools**, and select **Notion**.
  </Step>
  <Step title="Choose how people connect">
    Pick a **Shared account**, used by everyone, or **Personal accounts**, where each person connects their own Notion account the first time an agent uses the tool.
  </Step>
  <Step title="Sign in to Notion">
    Sign in to Notion and approve access to your workspace.
  </Step>
</Steps>

With personal accounts, each person only sees what they can see in Notion. With a shared account, everyone uses the access of the account that connected Notion.

## Add Notion to an agent

<Steps>
  <Step title="Open your agent in the Agent Builder">
    Create an agent, or open one you can edit.
  </Step>
  <Step title="Add the tool">
    In **Capabilities and knowledge**, click **Add capabilities** and select **Notion**.
  </Step>
  <Step title="Say where to look and write">
    In the instructions, name the pages or databases the agent should use, and what it can change.
  </Step>
</Steps>

By default, tools that read data run without asking (**Never ask**), and tools that create or change content use the **Low** level. Admins can change the level of each tool in **Spaces** > **Tools** > **Notion** > **Tools & stakes**:

- **High:** needs explicit user approval.
- **Medium:** users can save confirmations for specific tool inputs, or skip them for the rest of a conversation session.
- **Low:** users can completely disable confirmations.
- **Never ask:** runs automatically.

## Example instructions

```text
After each customer call, add a page to the "Customer calls" database in Notion with the customer name, the date, a summary of the call, and the next steps.
```
