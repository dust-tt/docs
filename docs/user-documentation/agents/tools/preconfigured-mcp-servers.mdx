Dust comes with preconfigured remote MCP servers for many popular tools. An admin adds them in a few clicks, without having to look up a server URL. The tools each server exposes come from the vendor, so check the vendor's documentation for the full list.

## Add a preconfigured MCP server (admins)

<Steps>
  <Step title="Open the tools of your workspace">
    Go to **Spaces** > **Tools** and click **Add Tool**.
  </Step>
  <Step title="Pick the server">
    Select the tool you want. Its server URL is already filled in.
  </Step>
  <Step title="Connect it">
    Follow the steps for its connection type (see the table below), then choose who can use it.
  </Step>
</Steps>

Then add the tool to an agent: in the Agent Builder, go to **Capabilities and knowledge**, click **Add capabilities**, and select it.

## Connection types

- **Sign in:** you sign in to the tool and approve access. Depending on the tool, you can connect a **Shared account** for everyone, or let each person connect their **Personal account**.
- **Your OAuth app:** you create an OAuth app in the tool first, then paste its client ID and secret in Dust. Follow the tool's page for the exact steps.
- **API key:** you paste an API key from the tool. Everyone who uses the tool shares this key.

See [Personal vs Shared Credentials](/docs/user-documentation/admins/tools-management/personal-vs-shared-credentials) for how each option works.
