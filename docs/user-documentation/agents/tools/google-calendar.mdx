## Overview

<Info>
  This tool uses personal credentials. It interacts with Google Calendar using
  the user accounts; it adapts to each user.
</Info>

## Admin: Setup in Dust

Go to Spaces > Tools in your Dust workspace, click `Add Tools`, and select Google Calendar.

You will then be redirected to an oAuth flow to connect an admin Google Calendar Account. This account only be used during the set up and users won't be able to query Google Calendar from this account.

By default this tool is added to the Company data Space, so accessible in all the workspace.

## Available Tools

| Tool | Description |
| --- | --- |
| **List Calendars** | List the calendars you can access. |
| **List Events** | List or search the events of a calendar for a day, a week, or a date range. |
| **Get Event** | Read the details of an event. |
| **Create Event** | Create a meeting or event. |
| **Update Event** | Reschedule an event, or change its location, attendees, or conference. |
| **Delete Event** | Delete or cancel an event. |
| **Check Availability** | Find the time slots when all participants are free. |
| **Get User Timezones** | Get the timezone of attendees. Only works for calendars shared with you. |

## Usage

Once the tool has been configured by the admin as described before, it can be selected on any agent: in the Agent Builder, simply click on `Add Tool` and select Google Calendar.

When users use an agent with the Google Calendar tool for the first time, the agent asks them to connect their own Google Calendar account.

They will have to click on the `Connect` button to connect their own Google Calendar credentials.

And they can click on the `Retry` button to replay the agent answer if not done automatically.
