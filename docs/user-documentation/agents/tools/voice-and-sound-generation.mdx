---
title: "Voice and sound generation"
description: "Let your agents turn text into speech or dialogue, transcribe audio and video files, and create sound effects."
---

Two built-in tools let your agents work with audio. **Speech generator** turns text into spoken audio or a dialogue between several speakers, and transcribes audio and video files. **Sound studio** creates short sound effects from a description. Speech generator is ready to use, and an admin adds Sound studio once.

## What your agent can do with these tools

| Tool | Action | What it does | Changes data |
| --- | --- | --- | --- |
| Speech generator | Generate speech | Turns text into an audio file read by one voice. | No |
| Speech generator | Generate dialogue | Turns several lines into one audio file, with a voice for each speaker. | No |
| Speech generator | Transcribe audio | Turns the speech in an audio or video file into text. The language is detected automatically. | No |
| Sound studio | Generate sound effect | Creates a sound effect from a description, and can make it loop. | No |

Each voice has a gender (female or male) and a language or accent: English (American), English (British), French, German, Dutch, Italian, Japanese, Hindi, Chinese, Spanish, Portuguese, Korean, Arabic, Turkish, Polish, Swedish, Russian, Indonesian, Filipino, Thai, or Vietnamese. The language sets the accent. It doesn't translate the text.

The list in Dust is the source of truth: it can change before this page does.

Generated speech, dialogue, and sound effects are saved as MP3 files. When you upload an audio file (MP3, M4A, WAV, OGG, or WebM) to a conversation, Dust transcribes it automatically, so any agent can read it without this tool.

## Before you start

- Speech generator is available in every workspace, with no setup.
- An admin needs to add Sound studio once (see below).
- Neither tool is available on workspaces that use their own model provider keys (BYOK).

## Add Sound studio to your workspace (admins)

<Steps>
  <Step title="Add the tool">
    Go to **Spaces** > **Tools**, click **Add Tool**, and select **Sound studio**.
  </Step>
</Steps>

See [Managing Tools](/docs/user-documentation/admins/tools-management/adding-an-mcp-server) for more on tool setup.

## Add the tools to an agent

<Steps>
  <Step title="Open your agent in the Agent Builder">
    Create an agent, or open one you can edit.
  </Step>
  <Step title="Add the tools">
    In **Capabilities and knowledge**, click **Add capabilities** and select **Speech generator**, **Sound studio**, or both. They need no configuration.
  </Step>
  <Step title="Say what audio to create">
    In the instructions, describe the voices, the length, and when the agent should create audio.
  </Step>
</Steps>

Every action of both tools is set to **Low** by default: users can completely disable confirmations.

- **Speech generator** isn't listed in **Spaces** > **Tools**, so its actions always stay at **Low**.
- For **Sound studio**, admins can change the level in **Spaces** > **Tools** > **Sound studio** > **Tools & stakes**. The levels are **High** (needs explicit user approval), **Medium** (users can save confirmations for specific tool inputs, or skip them for the rest of a conversation session), **Low**, and **Never ask** (runs automatically).

These actions only create new audio files or read the file you give them, so **Low** is usually enough.

## Example instructions

```text
When I share a meeting recording, transcribe it, then write a summary with the decisions and the next steps.
```

```text
Turn the research summary into a podcast dialogue between a female host and a male guest, both in American English. Keep it under three minutes.
```

## Limits

- **Generate speech:** up to 5,000 characters of text per audio file.
- **Generate sound effect:** from 0.5 to 30 seconds long.
- **Transcribe audio:** links only work from supported platforms, like YouTube, Vimeo, Loom, Zoom, Gong, or Google Drive. For other files, add the file to the conversation.
- **Credits:** each action costs 3 credits. See [Action credits](/docs/user-documentation/admins/usage-seats-and-credits/credits#action-credits).
