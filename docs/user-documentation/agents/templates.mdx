---
title: "Templates"
description: "Start an agent from a template for a common use case, then let Sidekick adapt it to your needs."
---

Templates give you a starting point for common use cases, like answering support questions or preparing sales briefs. When you pick a template, the Agent Builder opens with the template loaded, and [Sidekick](/docs/user-documentation/agents/default-agents/agent-builder-sidekick) drafts the first instructions and suggests tools and knowledge. You review the suggestions, adjust them, and publish your own version.

## Start from a template

<Steps>
  <Step title="Click Create agent">
    Open the agent picker in the message bar and click **Create agent**.
  </Step>
  <Step title="Open the templates">
    In the conversation that opens, under **Prefer to build manually?**, click **Start from template**.
  </Step>
  <Step title="Pick a template">
    In **Start with a template**, browse or search the templates, then select one. The Agent Builder opens with the template loaded.
  </Step>
  <Step title="Work with Sidekick">
    Sidekick proposes instructions and tools based on the template. Accept, edit, or decline each suggestion, then test the agent in the preview.
  </Step>
  <Step title="Publish">
    Name the agent, choose who can use it, and save. See [Create your first agent](/docs/user-documentation/agents/create-your-first-agent#publish-the-agent-and-choose-editors).
  </Step>
</Steps>

Not sure where to start? Browse the [Use cases and guides](/docs/user-documentation/getting-started/use-cases-and-guides/index) for ideas.
