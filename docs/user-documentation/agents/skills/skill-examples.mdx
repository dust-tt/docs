These three examples show how to build a skill around a real task. Copy them into the skill builder, then adapt the instructions to your own processes. To create a skill, see the [Skills overview](/docs/user-documentation/agents/skills/skills-overview#create-a-skill).

## Example 1: Add a CRM deal entry

When several agents write to your CRM, each one can format deals differently. A "CRM deal entry" skill gives every agent the same rules, and you maintain them in one place. Start with basic instructions and improve them over time: every agent that uses the skill gets the update.

### When to use this skill

```text
Use this skill to add a deal to our CRM. It covers our required fields, field names, and deal size rules.
```

### Instructions

Focus on what's specific to your company, like non-standard field names (SPQR in this example) or how you classify deal sizes.

```text
**Purpose**
Guide correct formatting for adding deals to the CRM.

**Key field rules**
The following fields are required to create a deal entry in the CRM.

1. Deal amount (amount_usd)
- Numeric only, no symbols
- Example: 15000

2. Deal size (size_bucket)
- small: < $2,000
- big: ≥ $2,000
- Example: $2,500 is big

3. SPQR stage (spqr_stage)
"SPQR" = Sales Pipeline Qualification Rating (legacy name)
Values: suspect | prospect | qualified | ready_to_close

4. Close date (close_date)
- Format: YYYY-MM-DD

**Example deal**
Deal name: Acme Corp - Enterprise
Amount USD: 15000
Size bucket: big
SPQR stage: qualified
Close date: 2026-03-15

**Common mistakes**
- Setting a $1,800 deal as "big" (it should be "small")
```

### Tools

This skill writes to your CRM, so add your CRM tool to the instructions. Type `/` in **Instructions** and select the tool, like HubSpot or Salesforce. Then add the skill to every agent that works on your sales pipeline.

## Example 2: Create branded Frames

Teams create charts, dashboards, and presentations with different agents, and colors, fonts, and layouts drift from one to the next. A "Branded Frames" skill makes every Frame follow your visual identity. Add it to any agent that creates [Frames](/docs/user-documentation/agents/frames/overview).

### When to use this skill

```text
Use this skill to create Frames that follow the company's branding and visual guidelines.
```

### Instructions

Include your brand colors, fonts, and design principles, and point to a Frame template the skill should start from. You can add the template in two ways:

- To use a template file from your computer, like a `.tsx` file, upload it in the skill's **Files** section.
- To use a template document or an existing Frame from a Space or Pod, type `/` in **Instructions**, select **Attach**, and search for it by title.

```text
Start every new Frame from the attached template.
Use our brand colors: primary <hex code>, accent <hex code>.
Use one accent color per chart, and keep titles in sentence case.
```

If needed, describe the layouts you expect, or explain what each color means and when to use it. Your team then maintains the template in one place, and every agent uses it.

## Example 3: Company tone of voice

Different people and agents write in different tones, so messages can sound too formal in one place and too casual in another. A "Tone of voice" skill keeps your communication consistent. Add it to customer-facing agents, internal communication assistants, and content agents.

### When to use this skill

```text
Use this skill when communicating externally with customers, prospects, or partners. It makes sure outbound communications follow our tone of voice, balancing professionalism with approachability.
```

### Instructions

Describe your voice and give concrete examples. Replace this example with your own guidelines.

```text
**Purpose**
Maintain consistent tone of voice across all external communications that reflects our company personality.

**Our Voice Principles**
1. **Clear, not corporate**: Use simple language. Avoid jargon unless necessary.
2. **Helpful, not robotic**: Be warm and human. Show you care about solving problems.
3. **Confident, not arrogant**: Be direct and knowledgeable without being condescending.
4. **Professional, not stuffy**: Maintain professionalism while being approachable.

**Word Choices**

Prefer:
- Help, assist (not "facilitate" or "leverage")
- Use (not "utilize")
- Simple (not "simplistic")
- Fix, resolve (not "remediate")
- Show, explain (not "demonstrate")
- We recommend (not "we would suggest that you might consider")

**Sentence Structure**
- Keep sentences short and scannable
- Use active voice: "We built this" not "This was built"
- Front-load important information
- Break long content into bullet points or sections

**Tone by Context**

**Customer Support:**
- Lead with empathy: "I understand this is frustrating"
- Take ownership: "I'll make sure we resolve this"
- Be specific about next steps and timelines

**Product Updates:**
- Lead with benefits, not features
- Use "you" and "your" to stay user-focused
- Celebrate improvements: "You can now..." instead of "We added..."

**Sales & Prospects:**
- Focus on value and outcomes, not features
- Be consultative, not pushy
- Ask questions to understand their needs

**Examples**

Bad - Too Corporate:
"We are pleased to inform you that the requested functionality has been implemented pursuant to your feedback."

Good - Our Voice:
"Good news! We've added the feature you asked for. Here's how to use it..."

Bad - Too Casual:
"Hey! So yeah, we totally messed up on that deployment lol. Our bad!"

Good - Our Voice:
"We made a mistake with yesterday's deployment and some features were temporarily unavailable. We've fixed the issue and added checks to prevent this in the future. Thanks for your patience."

**Common mistakes to avoid:**
- Using corporate buzzwords like "synergy," "leverage," "circle back"
- Being overly apologetic (one "sorry" is enough)
- Using passive voice to avoid responsibility
- An exclamation mark in every sentence
```

### Tools

This skill doesn't need tools: it's about how agents write. To give the agent examples of past messages, you can add communication tools with `/`, like Slack for internal messages, Gmail or Outlook for emails, and HubSpot or Zendesk for customer conversations.
