---
title: "Go Deep"
description: "Have your agent research a question for several minutes across company data, data warehouses, and the web before it answers."
---

Go Deep lets an agent research a question for several minutes across your company data, data warehouses, and the web before it answers. **@dust** can use it, and you can add it to your own agents.

## What your agent can do with Go Deep

| Capability | What it does |
| :--- | :--- |
| Plan the research | Writes a research plan and has a planning agent review it before starting. |
| Split the work | Hands parts of the question to sub-agents, so it can cover more ground without losing track. |
| Search company data | Searches and browses your company data, using the same data sources as the agent it runs in. |
| Query data warehouses | Runs SQL queries on your connected data warehouses, like Snowflake or BigQuery. |
| Search the web | Searches the web and reads pages for outside information. |

## When to use Go Deep

Agents only use Go Deep when you ask for it. Say "use Go Deep" or "do a deep dive", or ask for deep research or a full investigation across several sources. A long or complex question doesn't turn it on by itself.

Ask for Go Deep when you need:

- Research across several sources, like comparing what your docs, your CRM, and the web say about a competitor.
- Analysis over a lot of data, like finding patterns across hundreds of support tickets.
- A report that combines internal and external information, like market research.
- A thorough answer, and you can wait several minutes for it.

For a quick question, ask without Go Deep: the agent answers directly, even when the answer needs SQL or a web search.

## Add Go Deep to an agent

**@dust** already has Go Deep: ask it to go deep, and it turns the skill on.

To add Go Deep to your own agent:

<Steps>
  <Step title="Open your agent in the Agent Builder">
    Create an agent, or open one you can edit.
  </Step>
  <Step title="Add the skill">
    In **Capabilities and knowledge**, click **Add capabilities** and select **Go Deep**.
  </Step>
  <Step title="Save your agent">
    People using the agent can now ask it to go deep.
  </Step>
</Steps>

To use Go Deep in one conversation without changing an agent, type `/` in the message bar and select **Go Deep**.

## Example instructions

```text
When the user asks for a competitor deep dive, use Go Deep. Cover pricing, positioning, and recent news, and cite every source.
```

## Limits and credits

- A Go Deep run usually takes several minutes.
- It makes many more model and tool calls than a regular answer, so it uses more credits. See [Credits](/docs/user-documentation/admins/usage-seats-and-credits/credits).

## For admins

Go Deep isn't available when an admin turns off the **@deep-dive** agent. Turning **@deep-dive** back on makes Go Deep available again, in **@dust** and in every agent that has it.
