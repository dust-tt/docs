---
title: "Conversational building"
description: "Create, update, and archive agents and skills by describing what you want in a conversation."
---

Conversational building lets you create, update, and archive agents and skills from a conversation. Instead of opening the Agent Builder or the skill builder, you describe what you want, and the agent prepares the changes for you to review.

Most of what you can do by hand in the builders, you can also do in a conversation: write instructions, add tools, knowledge, and skills, change the model, rename, or archive. One exception: to add knowledge, or a tool that needs settings, to an agent, use the Agent Builder.

## Start conversational building

Conversational building opens on its own when you:

- Click **Create agent** or **Create skill**.
- Click **Edit** on an agent in **Manage agents** or on a skill in **Manage skills**, or **Edit agent** or **Edit skill** in the details panel.

The conversation shows **Prefer to build manually?** with options to open the builder instead.

In any other conversation, type `/` in the message bar and select the **Build Agents and Skills** skill.

## How it works

### The agent suggests, you decide

The agent never changes an agent or a skill on its own. Each change it wants to make shows up in the conversation as a suggestion card, and nothing happens until you accept the card.

### One card can hold several changes

A card groups changes that belong together. For example, a single card can add a skill to an agent and update the agent's instructions to explain when to use that skill. You accept or decline the whole set at once.

When a request involves separate changes, the agent suggests several cards, and you review them one by one.

### Review the changes

You can review a suggestion in two places:

- **In the card**: see a summary of the proposed changes directly in the conversation.
- **In the side panel**: open the agent or skill to see the changes in the context of its full configuration.

### Changes apply immediately

When you accept a card, the changes are applied right away:

- A newly created agent or skill is available immediately.
- An update creates a new version of the agent or skill.

## Permissions

The agent acts on your behalf and can only do what you can do yourself. Depending on the change, you need:

- The **Create agents** permission, to create an agent.
- The **Create skills** permission, to create a skill.
- To be an editor of the agent or skill, to update or archive it.

If you don't have the required permission, the change can't be suggested or applied.

## Examples

### Getting started

- "Create an agent that reads my calendar and prepares a summary of my meetings for the week."
- "Create a skill that writes customer-facing release notes following our tone of voice."
- "Add the web search tool to @research and explain in its instructions when to use it."
- "Archive my old test-agent."

### Advanced use cases

You can also change many agents and skills at once. The agent only changes the ones you can edit:

- "Rename all agents to follow our naming convention: team name first, then purpose."
- "Find all agents that use the GitHub tool, extract how they use it into a shared skill, then add that skill to each of these agents in place of the tool."
- "Find all agents still using an older model and switch them to the latest one."
