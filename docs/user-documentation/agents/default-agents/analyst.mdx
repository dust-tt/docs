`@analyst` is the default agent that answers questions about how your Dust workspace is used. It queries your workspace's usage data and only reports the figures that it gets from that data. It never estimates.

<Note>
Only workspace admins and managers can see and use `@analyst`. Members don't see it in the agent list.
</Note>

## Ask @analyst a question

You can ask `@analyst` a question in two ways:

- Mention `@analyst` in any conversation.
- In **Admin** > **Analytics**, click **Ask analyst** at the top right. `@analyst` opens in a side panel and can read the period and filters selected on the page.

For example, you can ask:

- "Which agents were used the most this month?"
- "How many credits did we use last week, by model?"
- "Show me the weekly active users since September."

## What @analyst can answer

`@analyst` reads the same data as the [Analytics](/analytics) page of your workspace (**Admin** > **Analytics**):

- **Credits:** headline figures and the agents, members, or tools that use the most credits.
- **Activity:** message counts, active users, and how often tools, skills, and Frame apps ran.
- **Trends:** how credits and active users change by day, week, or month.
- **Workspace inventory:** the agents, skills, tools, models, tags, members, and groups of your workspace, and what each agent uses.

You can break down the results by agent, member, group, model, source, API key, trigger, Pod, tool, skill, or tag. When a chart shows the answer better than text, `@analyst` creates a [Frame](/docs/user-documentation/agents/frames/overview).

## When to use @analyst

Use `@analyst` when you want a quick answer to a usage question without building a filtered view on the Analytics page. For example, while you review adoption in a team meeting or check credit usage before a renewal.

## Turn @analyst on or off

Dust provides `@analyst`, so you can't edit its instructions or tools in the Agent Builder. Workspace admins can turn it off or back on for the whole workspace in the governance settings. Unlike the other default agents, you can't turn it off in **Manage agents**.

<Steps>
  <Step title="Open the Features tab">
    In **Admin** > **Governance**, open the **Features** tab.
  </Step>
  <Step title="Use the Workspace Analyst switch">
    Turn **Workspace Analyst** off or on. The setting controls both `@analyst` and the Workspace Analytics skill.
  </Step>
</Steps>
