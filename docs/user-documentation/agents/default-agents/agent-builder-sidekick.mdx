title: "Sidekick"
description: "Use Sidekick in the Agent Builder to draft instructions, get tool, skill, and knowledge suggestions, and improve your agents."
---

Sidekick is an assistant built into the Agent Builder. It helps you create new agents and improve existing ones through a conversation. You describe what you want the agent to do, and Sidekick drafts the instructions and suggests tools, skills, knowledge, and a model. You review each suggestion before it changes anything.

<Info>
Sidekick only works in the Agent Builder. You can't mention it in a conversation, and it isn't available through the API.
</Info>

## Open Sidekick

Sidekick is in the right panel of the Agent Builder, next to the **Preview** and **Insights** tabs. You can open it in several ways:

- **Create a new agent:** in the left sidebar, click **Agents** > **Manage agents** > **Create agent**. Under **Prefer to build manually?**, click **Open manual builder**.
- **Edit an existing agent:** open the agent in the Agent Builder. Sidekick reads the current configuration, including the changes that you haven't saved.
- **Start from a template:** pick a template from the gallery. Sidekick uses the template as a guide and asks you questions to adapt it to your workflow.
- **Convert a conversation:** turn a conversation that went well into a reusable agent. See [Turn a conversation into an agent](#turn-a-conversation-into-an-agent).

## Create an agent with Sidekick

<Steps>
  <Step title="Describe your agent">
    In the Sidekick panel, describe what the agent should do. For example: "I want an agent that helps my team write weekly client updates based on our CRM data and Slack channels."
  </Step>
  <Step title="Answer Sidekick's questions">
    Sidekick asks clarifying questions when it needs more details. For a complex use case, it can offer to research your workspace's data to understand your requirements. This takes a few minutes, and Sidekick always asks before it starts.
  </Step>
  <Step title="Review the suggestions">
    Sidekick shows its changes to the instructions as inline suggestions: additions in green and removals in red. Accept or reject each one. You can also edit the instructions yourself at any time.
  </Step>
  <Step title="Add tools, skills, and knowledge">
    Sidekick suggests tools, skills, knowledge, and a model. Each suggestion appears as a card that you can accept in one click.
  </Step>
  <Step title="Test and save">
    Open the **Preview** tab to test the agent, then save it.
  </Step>
</Steps>

## Improve an existing agent

When you open an existing agent, Sidekick looks at its configuration, the feedback from its users (thumbs up and thumbs down), and its usage. It then suggests changes, for example:

- Rewrite or simplify the instructions.
- Add tools or skills that the agent is missing.
- Merge sections of the instructions that repeat each other.
- Add knowledge sources from your workspace.

Sidekick doesn't suggest changes only to reword sentences. It suggests a change when it finds a gap that affects how the agent works.

## Turn a conversation into an agent

If a conversation gave you a workflow that you want to reuse, turn it into an agent:

<Steps>
  <Step title="Open the conversation menu">
    In the conversation, open the `...` menu at the top and click **Convert to agent**.
  </Step>
  <Step title="Review the draft">
    The Agent Builder opens, and Sidekick drafts an agent with the same instructions, tools, and knowledge as the conversation. Review its suggestions, then test and save the agent.
  </Step>
</Steps>

**Convert to agent** is available on the web app on desktop, if you have the permission to create agents.

## What Sidekick can do

- Draft and edit the instructions with suggestions that you accept or reject.
- Suggest tools, skills, and a model to add or remove.
- Find knowledge sources in your workspace and suggest which ones to add.
- Suggest adding or removing a sub-agent, and check that the agent and its sub-agents work well together.
- Draw a diagram of the agent's workflow when you ask for one.
- Suggest use cases when you start from scratch.
- Show buttons for the usual next steps, so you type less.

## How suggestions work

- **You keep control.** Sidekick never applies a change by itself. You accept or reject each suggestion.
- **You can edit at any time.** The form isn't locked while Sidekick works. If your edit conflicts with a pending suggestion, Sidekick removes that suggestion.
- **Suggestions are saved.** If you leave the Agent Builder with pending suggestions, they're still there when you come back. The Sidekick conversation itself isn't saved between visits.
- **Each editor has their own conversation.** When several editors open the same agent, each one gets their own Sidekick conversation. Everyone sees the pending suggestions of all editors.

## What Sidekick can see

Sidekick knows which tools, skills, and knowledge sources are available in your workspace. To suggest knowledge, it can find data sources and document titles in any Space you're a member of, including restricted Spaces. To read document contents, it only uses the Company Data Space.

If the data source you need isn't connected to your workspace, Sidekick tells you and suggests that you ask a workspace admin to connect it.

## Credits and limits

Sidekick messages are free. They don't use your workspace's credits. Two fair-use limits apply:

- Each member can send up to 100 Sidekick messages in 24 hours, or 200 on the Enterprise plan.
- Sidekick messages count toward your workspace's fair-use limit on the total cost of free usage.

When you reach a limit, Sidekick isn't available until the limit resets.

## Limitations

- Sidekick can't create or edit triggers. It explains how to set them up yourself. See [Triggers](/docs/user-documentation/agents/triggers/index).
- Sidekick can't create skills. It can suggest existing skills.
- You can't customize how Sidekick behaves for your workspace.
