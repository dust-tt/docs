title: "@dust Agent"

---

`@dust` is the general-purpose agent that Dust sets up in every workspace. It can use the company data and tools available in the Company Data Space to find and analyze information, research topics on the web, and create content like documents, presentations, images, and dashboards.

## Talk to @dust

When you start a new conversation, `@dust` is already selected in the message input, so you can type your question and send it. You can also mention `@dust` in any conversation. In an existing conversation, the agent you last talked to stays selected for your next message.

`@dust` only uses the company data and tools that you can access.

## What @dust can do

`@dust` comes with a set of default skills that it uses when your request needs them, for example to search your company knowledge, find a relevant skill, create a [Frame](/docs/user-documentation/agents/frames/overview), or [go deep](/docs/user-documentation/agents/go-deep) on a complex question. See [Default skills](/docs/user-documentation/agents/skills/default-skills) for the full list.

`@dust` can also suggest other agents of your workspace when you ask which agent to use for a task, and it can remember things about you across conversations, like your role or your preferences.

Use `@dust` for:

- Questions about your company's documents and connected data sources.
- Quick requests that don't need a dedicated custom agent.
- Getting started with Dust before you build agents for your team.

For extended research across many sources, mention [`@deep-dive`](/docs/user-documentation/agents/default-agents/deep-dive-agent) instead.

## Choose a model

By default, `@dust` uses the **Standard** auto model, or **Basic** if your model access doesn't include Standard. To use a different model for your next message, pick one from the model picker in the message input. This doesn't change the agent for anyone else. See [Auto models and the model picker](/docs/user-documentation/agents/model-selection).

## Turn @dust on or off

Dust provides `@dust`, so you can't edit its instructions, tools, or skills in the Agent Builder. Workspace admins can turn it off or back on for the whole workspace:

<Steps>
  <Step title="Open Manage agents">
    In the left sidebar, click **Agents**, then **Manage agents**.
  </Step>
  <Step title="Open the Dust tab">
    The **Dust** tab lists the default agents.
  </Step>
  <Step title="Use the switch">
    Click the switch on the `@dust` row to turn it off or on.
  </Step>
</Steps>

When `@dust` is off, members can still use the other agents in the workspace.
