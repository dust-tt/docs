`@deep-dive` is the default agent for complex questions that need a thorough investigation. It plans the research, runs several tasks in parallel, and combines the results into one answer with citations. A complex investigation can take several minutes.

<Note>
`@deep-dive` is available on paid plans and free trials. It isn't available on the Free plan.
</Note>

## Ask @deep-dive a question

Mention `@deep-dive` in a conversation and ask your question. While it works, the conversation shows its progress and what each sub-agent is doing.

`@deep-dive` adapts to your question:

- **Simple questions:** it answers directly, usually in under a minute.
- **Complex questions:** it plans the investigation, splits the work into tasks, and gives each task to a sub-agent. Up to six sub-agents run at the same time. When they finish, `@deep-dive` combines their findings into a report.

## What @deep-dive can use

`@deep-dive` uses the knowledge and tools of the Company Data Space:

- **Company data:** it searches, browses, and reads the documents from your connected data sources, like Slack channels, Notion pages, or GitHub repositories.
- **Data warehouses:** it explores the tables of your connected data warehouses, like [Snowflake](/docs/user-documentation/agents/tools/snowflake) or [BigQuery](/docs/user-documentation/agents/tools/bigquery), and runs SQL queries to answer quantitative questions. You don't need to know which table holds the data.
- **Web search and browse:** it searches the web and reads pages for up-to-date external information.
- **Other tools:** when a task needs a tool that your workspace has, like a CRM or a project management tool, it gives that task to a sub-agent that uses the tool.
- **Frames:** when a chart or a dashboard explains the answer better than text, it creates a [Frame](/docs/user-documentation/agents/frames/overview).

Every answer cites its sources, so you can check the documents, web pages, or queries it used.

## When to use @deep-dive

Use `@deep-dive` for questions like these:

- An analysis that combines internal documents, data warehouse figures, and web sources.
- Competitive research that compares your internal strategy with market information.
- A regulatory or legal review that compares your internal policies with current external sources.
- A technical investigation across code repositories, documentation, and database metrics.
- A review of a large number of documents.

For quick questions, [`@dust`](/docs/user-documentation/agents/default-agents/dust) is faster.

## Permissions

`@deep-dive` only accesses data that you can access. When a tool uses personal authentication, `@deep-dive` uses your account. Its sub-agents have the same permissions as you.

## Limitations

- `@deep-dive` can't query tables from spreadsheets or Notion databases.
- `@deep-dive` only uses the knowledge of the Company Data Space. It doesn't search other Spaces. To use a document or a folder from another Space, attach it to your message.

## Turn @deep-dive on or off

Dust provides `@deep-dive`, so you can't edit its instructions or tools in the Agent Builder. Workspace admins can turn it off or back on for the whole workspace:

<Steps>
  <Step title="Open Manage agents">
    In the left sidebar, click **Agents**, then **Manage agents**.
  </Step>
  <Step title="Open the Dust tab">
    The **Dust** tab lists the default agents.
  </Step>
  <Step title="Use the switch">
    Click the switch on the `@deep-dive` row to turn it off or on.
  </Step>
</Steps>
