## What is `@help` and how to use it?

`@help` is a default agent dedicated to answering questions about how to use Dust itself. Mention it with `@help` in the composer whenever you're unsure how a Dust feature works, or open it directly from the user menu.

Unlike other default agents, `@help` cannot be deactivated by workspace admins: it's always available.

## How `@help` works

`@help` searches Dust's public documentation and the dust.tt website to answer your question, and always grounds its answers in what it finds there rather than guessing. If it can't find an answer in the documentation, it says so instead of inventing one.

At the end of its answers, `@help` points you to the official documentation ([docs.dust.tt](https://docs.dust.tt)) and to the Dust community Slack for further support.

If you ask `@help` about agents already configured in your workspace, it can also suggest relevant existing agents for your needs.

## When to use `@help`

Use `@help` for:

- Questions about how a Dust feature works or how to set it up.
- Understanding the difference between platform capabilities (models, tools, skills, permissions).
- Getting pointed to the right documentation page or community resource.

`@help` only answers questions about Dust; it will let you know if your question is unrelated to the platform.
