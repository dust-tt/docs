`@help` is the default agent that answers questions about how to use Dust. It searches the Dust documentation and website, and bases its answers on what it finds there. If it can't find the answer, it tells you instead of guessing.

## Ask @help a question

You can reach `@help` in two ways:

- Mention `@help` in a conversation and ask your question.
- Open the user menu, go to **Help**, and click **Ask @help**. The same menu has example questions, like "How do I invite new users?", that you can send in one click.

At the end of its answers, `@help` links to the [Dust documentation](https://docs.dust.tt) and to the Dust community on Slack.

## When to use @help

Use `@help` to:

- Learn how a Dust feature works or how to set it up.
- Understand the difference between models, tools, skills, and permissions.
- Find the right documentation page.
- Find agents in your workspace that fit what you need.

`@help` only answers questions about Dust. If you ask about something else, it tells you that it can't help with that.

## Availability

`@help` is always available. Unlike the other default agents, workspace admins can't turn it off. Dust provides `@help`, so you can't edit its instructions or tools in the Agent Builder.
