---
title: "Integrations"
description: "Use your Dust agents from the tools your team already works in."
---

Integrations bring your agents to the places your team already works, and let other apps call them. They're different from [Tools](/docs/user-documentation/agents/tools/index), which let agents act in other apps, and from [Connections](/docs/user-documentation/admins/connections-management/index), which sync company data into Dust.

## Talk to agents where you work

| Integration | What it does |
| --- | --- |
| [Dust in Slack](/docs/user-documentation/agents/integrations/dust-in-slack/index) | Call agents from Slack channels, threads, and direct messages |
| [Dust in Teams](/docs/user-documentation/agents/integrations/dust-in-teams) | Call agents from Microsoft Teams |
| [Browser extension](/docs/user-documentation/agents/integrations/browser-extension) | Use agents from a side panel in Chrome, Firefox, and Chromium-based browsers, with the current tab as context |
| [Raycast extension](/docs/user-documentation/agents/integrations/raycast-extension) | Run an agent on text you've selected anywhere on your Mac |
| [Send and forward email to agents](/docs/user-documentation/agents/integrations/send-and-forward-email-to-agents) | Email an agent, copy it on a thread, or forward it a message |
| [Google Sheets add-on](/docs/user-documentation/agents/integrations/google-sheets-add-on) | Use agents in your spreadsheets |
| [Dust in Zendesk](/docs/user-documentation/agents/integrations/dust-in-zendesk) | Use agents from inside Zendesk |
| [Dust MCP Server](/docs/user-documentation/agents/integrations/dust-mcp-server) | Use Dust from MCP clients such as IDEs and AI assistants |

## Automate with other apps

| Integration | What it does |
| --- | --- |
| [Zapier](/docs/user-documentation/agents/integrations/zapier) | Run an agent from a Zap |
| [Make.com](/docs/user-documentation/agents/integrations/make-com) | Run an agent from a Make scenario |
| [n8n](/docs/user-documentation/agents/integrations/n8n) | Run an agent from an n8n workflow |
| [Power Automate](/docs/user-documentation/agents/integrations/power-automate) | Run an agent from a Power Automate flow |
| [Slack workflows](/docs/user-documentation/agents/integrations/dust-in-slack/slack-workflows) | Run an agent from Slack Workflow Builder |

To run agents on a schedule or on events from GitHub, Jira, Linear, Zendesk, Fathom, or a custom webhook without a third-party tool, use [Triggers](/docs/user-documentation/agents/triggers/index).

## Meetings

[Meeting transcripts](/docs/user-documentation/agents/integrations/meeting-transcripts) explains how to connect notetaker apps such as Granola or Fathom, so agents can work with your meetings.
