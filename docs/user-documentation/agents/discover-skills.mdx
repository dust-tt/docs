---
title: "Discover Skills"
description: "Let your agent find and turn on skills from your workspace when a request matches them."
---

Discover Skills lets an agent find skills shared with your workspace and turn one on when a request matches it. You don't need to add every skill to the agent ahead of time. **@dust** already has it, and you can add it to your own agents.

## What your agent can do with Discover Skills

| Capability | What it does |
| :--- | :--- |
| List available skills | Sees the skills it can use: workspace skills set to **Members and agents**, the skills Dust provides, and your favorite skills. |
| Turn on a skill | Turns on the skill that matches the request, for the current conversation. |
| Use the skill | Follows the skill's instructions and uses its tools and knowledge. |

Once the agent turns on a skill, the skill stays on for that agent for the rest of the conversation.

## When to use Discover Skills

Add Discover Skills when:

- Your workspace has many skills, and you don't want to add each one to the agent.
- You want the agent to pick up new skills as your team shares them, without editing the agent.

## Make a skill available to agents

Agents with Discover Skills only see workspace skills set to **Members and agents**. In the skill builder, **Availability** has three options:

| Availability | Who can use the skill |
| :--- | :--- |
| **Editors only** | Only the skill's editors. |
| **Members** | Everyone in the workspace, from the message bar and the Agent Builder. |
| **Members and agents** | Everyone in the workspace, plus any agent with Discover Skills, including **@dust**. |

New skills start as **Editors only**. Not everyone can set a skill to **Members and agents**. If you can't, ask an admin.

## Add Discover Skills to an agent

**@dust** already has Discover Skills.

To add Discover Skills to your own agent:

<Steps>
  <Step title="Open your agent in the Agent Builder">
    Create an agent, or open one you can edit.
  </Step>
  <Step title="Add the skill">
    In **Capabilities and knowledge**, click **Add capabilities** and select **Discover Skills**.
  </Step>
  <Step title="Save your agent">
    The agent can now turn on matching skills during a conversation.
  </Step>
</Steps>

## Example instructions

```text
Before answering, check whether a workspace skill matches the request, like our brand guidelines or the sales playbook, and use it.
```
