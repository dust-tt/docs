---
title: "Self Improving Skills"
description: "Get suggested edits for your skills, based on how people use them in conversations."
---

Self-improving skills look at how people use your skills in conversations and suggest edits to make them work better. Dust reviews conversations that used a skill, finds where the skill fell short, and proposes concrete changes. The skill's editors review each suggestion, and nothing changes until an editor accepts it.

If you don't see the self-improvement settings in the skill builder, the feature isn't available for your workspace.

## How it works

<Steps>
  <Step title="Dust analyzes conversations">
    Every night, Dust reviews recent conversations that used the skill. It looks at the feedback people left, like thumbs up or down and written comments, and at other signs: a person correcting the agent, a tool the agent should have used but didn't, or a conversation that went off track.
  </Step>
  <Step title="Dust suggests edits">
    Based on this analysis, Dust proposes changes to the skill, like clearer instructions or a better description of when to use it.
  </Step>
  <Step title="Editors review the suggestions">
    Editors accept or decline each suggestion in the skill builder.
  </Step>
</Steps>

## Review suggestions

When new suggestions are ready, Dust starts a conversation with the skill's editors. You can accept or decline the suggestions there, or ask **@dust** to refine them.

You can also review them in the skill builder. When a skill has pending suggestions, the **Suggestions** panel opens next to the builder and shows each change as a diff. For each suggestion, click **Accept** to apply it to the skill builder, or **Decline** to dismiss it. Then click **Save** to save the accepted changes.

While suggestions are pending, **Instructions** is read-only and **History** is hidden.

## Turn self-improvement on or off

Self-improvement is optional, for each skill and for the whole workspace.

**For one skill:** in the skill builder, go to **Skill settings** > **Self-improvement** and switch **Self-improve** on or off. If an admin has locked the setting for this skill, you can't change it.

**For the workspace (admins):** go to **Admin** > **Governance** > **Agents & Skills**. In **Self-improving skills**, turn off **Allow self-improving skills** to stop all analysis and suggestions. The **Skills** table in the same section shows each skill's editors and current spend. For each skill, admins can turn self-improvement on or off, set a cost cap, and lock the setting so editors can't change it.

## Pricing

On plans with credits, self-improving runs are shared automations: they use workspace credits and count toward the shared automation cap. On other plans, self-improving skills are priced as programmatic usage. See [Credits](/docs/user-documentation/admins/usage-seats-and-credits/credits).

In **Admin** > **Credits** > **Settings**, admins can set two limits:

- **Default cost cap per skill**: the maximum a skill can spend on self-improvement in a billing period. Once a skill reaches it, no new runs start for that skill until the next billing period. Admins can set a different cap for a skill in the **Skills** table in **Admin** > **Governance** > **Agents & Skills**.
- **Global spending cap**: the maximum cost per month across all skills. Once reached, no new runs start until the next billing month.

By default, Dust processes conversations through the batch APIs of model providers, which costs less than real-time calls. Turning off batch processing raises the cost. See [Processing modes and Zero Data Retention (ZDR)](#processing-modes-and-zero-data-retention-zdr).

## Privacy and data usage

### What data is used and how

Conversation content is processed using the LLM provider(s) already configured and approved in your Dust workspace. Self-improving skills does not introduce any additional model providers or data sub-processors.

The following data is used:

- Conversation transcripts (messages, tool calls, and agent responses)
- User feedback (thumbs up/down and written comments)
- Current skill configurations (instructions, tools)

### Customer instruction

By enabling _Self-improving skills_, Customer instructs Dust to process such data as Data Processor under the Data Processing Addendum for the purpose of providing self-improving skills for Customer's own workspace. Customer confirms that it has identified an appropriate GDPR lawful basis for this processing, has provided required notices to relevant users, and has obtained any required authorisation.

### No model training

Dust does not train any model or fine-tune any foundation model based on your conversations. Self-improving skills only uses conversations to improve the instructions and configuration of your own skills.

### Data isolation

There is no cross-workspace data sharing. Conversations from your workspace are only used to improve skills within your workspace. Nothing is shared across workspaces or used for any other purpose.

### Data retention

Resulting suggestions and analysis summaries are stored within Dust infrastructure, scoped to your workspace, and subject to the same data governance policies that apply to all your Dust data.

### Processing modes and Zero Data Retention (ZDR)

Self-improving skills support two processing modes, which have different implications for Zero Data Retention (ZDR).

#### Batch mode (default)

By default, self-improving skills use LLM Batch Mode to process conversations nightly. Batch APIs are not covered by ZDR guarantees from any of the supported providers (Anthropic, OpenAI...). This is by design of batch processing: batch results must be temporarily stored server-side until they are processed and Dust retrieves them. To minimize exposure, Dust immediately deletes batch data from the provider after downloading results.

In practice, this is not different than a normal conversation, except that the conversations can take up to 24 hours to be processed by the LLM providers.

#### Streaming mode (ZDR-eligible)

Workspace admins can disable batch mode independently from the self-improving skills feature itself, with **Enable batch processing** in **Admin** > **Governance** > **Agents & Skills** > **Self-improving skills**. When batch mode is disabled, self-improving skills process conversations using synchronous streaming calls, which are covered by ZDR guarantees. Note that streaming mode is more expensive than batch mode.

<Warning>
  If your workspace has a strict ZDR requirement, either turn off **Enable batch processing** (to keep self-improving skills active but ZDR-compliant) or turn off **Allow self-improving skills** entirely.
</Warning>
