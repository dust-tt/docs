Data sources hold the company knowledge your agents use. There are three kinds: connections that sync content from your tools, folders where you upload files and tables, and websites that Dust crawls. Each data source lives in a Space, and only people who have access to that Space can use it in their agents.

## Types of data sources

| Type | What it holds | How it stays up to date |
| --- | --- | --- |
| [Connections](/docs/user-documentation/data-sources/connections) | Content from tools like Google Drive, Notion, Slack, Confluence, or Snowflake | Dust syncs changes automatically. |
| [Folders](/docs/user-documentation/data-sources/folders) | Documents and tables you upload, or send with the API | You update the content yourself, in Dust or with the API. |
| [Websites](/docs/user-documentation/data-sources/websites) | Pages from a public website | Dust crawls the site again on the schedule you choose. |

Files you attach in a conversation work differently: they're only available in that conversation. See [Conversation files](/docs/user-documentation/data-sources/conversation-files/conversation-files).

## How data reaches your agents

<Steps>
  <Step title="Admins set up connections">
    Admins connect tools in **Spaces** > **Connections** and choose what to sync.
  </Step>
  <Step title="Data is added to Spaces">
    In a Space, click **Add data** to add connected data, upload a folder, or add a website. In a regular Space, members can add data. In the Company Data Space, everyone in the workspace can read the data, but only admins, managers, and the people and groups selected in its **Space settings** can add or change it.
  </Step>
  <Step title="Builders add knowledge to agents">
    In the Agent Builder, builders select data from the Spaces they have access to and choose how the agent uses it. See [Knowledge](/docs/user-documentation/agents/knowledge).
  </Step>
</Steps>

The @dust agent searches the connections and folders in the Company Data Space on its own. It doesn't search websites, Snowflake, or BigQuery: add those to an agent as knowledge instead.
